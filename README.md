# RT-Spark Edge AI Consumer Product

BCA182 Embedded Systems Programming — Laboratory Activity 4  
Design and Development of an Edge AI Consumer Product

## Overview

This project will develop an original consumer product using the
RT-Spark development board. It will acquire sensor data, perform
preprocessing and trained machine learning inference on the STM32
microcontroller, and provide understandable local feedback.

Inference and immediate user feedback must operate without an
Internet connection.

## Required Development Stack

- RT-Spark / Spark-1 with STM32F407ZGT6
- Visual Studio Code with PlatformIO
- STM32Cube HAL and/or LL drivers
- FreeRTOS
- A compatible C/C++ implementation of the trained model

## Development Plan

1. Select and justify the consumer product concept.
2. Verify the board, onboard sensors, and applicable modules.
3. Establish the STM32Cube and FreeRTOS firmware.
4. Collect and label data from the actual board.
5. Train, evaluate, and export a compact model.
6. Integrate on-device inference, feedback, and diagnostics.
7. Test the complete system and document measured results.

## Current Status

Initial repository setup. Product selection, hardware verification,
firmware development, data collection, and evaluation are pending.
